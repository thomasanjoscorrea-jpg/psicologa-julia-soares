# Site – Psicóloga Julia Soares

Prévia de proposta de site (HTML, CSS e JavaScript puros, sem dependências).

- `index.html` – página completa
- `img/` – fotos (versões `.webp` em 360 e 560 px para carregar mais rápido, `.jpg` como reserva) e `og-julia.jpg` (imagem de compartilhamento)

## Seções

Início · Sinais que merecem atenção · Para cada fase (idades) · Atendimentos · Sobre · Como funciona · Para os pais · Modalidades · Avaliações · Dúvidas · Contato

## Conferir com a Julia antes de publicar

- Faixas etárias da seção "Para cada fase" (até 6, 7 a 11, 12 a 17 anos)
- Dúvidas novas: sessões semanais e recibo para reembolso de plano de saúde
- `areaServed` no código (Sarandi, Maringá, Paraná)

## Ao publicar (após aprovação)

1. Remova a faixa "Prévia de proposta", a meta `robots` do `index.html` e o arquivo `robots.txt`.
2. Troque os caminhos relativos de `og:image` e `image` (schema) pela URL completa do site, ex.: `https://seudominio.com.br/img/og-julia.jpg`.
3. Adicione `<link rel="canonical" href="https://seudominio.com.br/">` e um `sitemap.xml`.
4. Cadastre o site no Google Search Console e no Perfil da Empresa no Google.
